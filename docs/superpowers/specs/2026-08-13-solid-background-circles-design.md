# 设置面板纯色背景圆形控件设计

日期：2026-08-13

## 目标

减少设置面板中背景选项占用的空间，同时保留图片背景的可辨识性。

## 设计

- 图片背景选项继续使用现有的 4:3 缩略图卡片。
- `kind: 'solid'` 的纯色背景选项改为 38×38px 圆形色块，与强调色按钮尺寸一致。
- 纯色背景继续根据当前浅色/深色主题展示对应颜色。
- 纯色背景选中态使用与强调色按钮一致的白色内圈，并保留外部强调色焦点/选中提示。
- 背景区域保留原有顺序：图片背景在前，纯色背景在后；布局允许纯色色块紧凑换行。

## 行为与无障碍

- 不修改背景偏好的读取、写入、恢复与事件通知逻辑。
- 保留每个按钮现有的 `aria-label`、`aria-pressed` 和 `data-background-choice`。
- 保留键盘操作、悬停、按压及减少动态效果策略。

## 验证

- 添加 UI 契约测试，确认纯色背景通过 `data-background-kind="solid"` 获得圆形、38×38px 样式。
- 确认图片背景仍保留 4:3 缩略图样式。
- 运行 `npm test -- --run`、`npm run check` 和 `npm run build`。
