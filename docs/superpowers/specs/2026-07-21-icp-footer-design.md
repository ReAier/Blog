# 博客 ICP 备案信息页脚设计

日期：2026-07-21

## 背景

`blog.reaier.top` 的 ICP 备案申请已于 2026-07-20 审核通过，备案号为 `赣ICP备2026016483号`。当前全站页脚仅展示版权信息和 Astro 构建文案，尚未展示备案信息。

## 目标

在全站页脚中清晰、统一地展示备案号，并提供前往工信部备案管理系统的链接，同时保持博客现有的简洁视觉风格和响应式布局。

## 设计

- 在 `SiteFooter.astro` 的页脚信息区域加入独立备案链接。
- 链接文本固定为 `赣ICP备2026016483号`。
- 链接目标使用工信部备案管理系统：`https://beian.miit.gov.cn/`。
- 链接在新标签页打开，并设置 `rel="noopener noreferrer"`。
- 桌面端沿用现有横向页脚布局；窄屏端沿用现有纵向换行布局。
- 链接默认继承页脚的弱化文本颜色；悬停和键盘聚焦时显示清晰的强调色及可见焦点，不引入新的视觉组件。

## 范围

涉及：

- `src/components/SiteFooter.astro`
- `src/styles/global.css`（仅在现有通用链接样式不足时增加页脚链接样式）
- 对应的静态输出或组件测试验证

不涉及：

- 域名 DNS、服务器或 CDN 配置
- 公安联网备案信息
- 备案主体名称或其他未提供的信息
- 页脚整体重构

## 验收标准

1. 所有使用 `BaseLayout.astro` 的页面均展示 `赣ICP备2026016483号`。
2. 点击备案号会在新标签页打开工信部备案管理系统。
3. 链接包含安全属性 `noopener noreferrer`。
4. 链接在鼠标悬停和键盘聚焦时可明确识别。
5. 桌面端和手机端页脚布局均不溢出、不遮挡其他内容。
6. Astro 类型检查、项目测试和生产构建通过。
