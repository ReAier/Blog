# Aier's blogs 液态动效系统设计

**日期：** 2026-07-12  
**状态：** 待用户书面审阅  
**范围：** 在保持 Astro 静态架构、低服务器占用和阅读体验的前提下，为全站导航与交互增加克制的液态融合动效。

## 1. 目标

- 为顶部导航、页面切换、卡片、目录、代码复制、主题设置、移动菜单等主要操作提供一致的动态反馈。
- 使用低饱和、柔和模糊和轻微形变构成“液态融合”视觉语言。
- 动效明显但不花哨，文章正文阅读期间保持安静。
- 不增加后台服务、数据库或服务器常驻内存。
- 桌面端提供完整效果，移动端自动降低帧率、分辨率和动效强度。
- WebGL、JavaScript或动画能力不可用时，网站仍可完整阅读和操作。

## 2. 非目标

- 不引入大型 3D 模型、视频背景或高分辨率纹理。
- 不制作持续抢夺注意力的密集粒子、故障扫描或大角度 3D 翻转。
- 不让动画成为导航、正文或无障碍操作的必要条件。
- 不新增 CMS、API、用户系统或数据库。
- 不改变现有 Markdown 内容模型和部署方式。

## 3. 实现方向

采用原生 CSS、少量浏览器 JavaScript、Astro 页面过渡能力和自定义轻量 WebGL Shader：

- CSS 负责微交互、进入动画、面板、卡片、按钮和主题颜色过渡。
- 页面过渡控制器负责内部导航、旧页面退出、新页面进入和组件重新初始化。
- 自定义 WebGL Canvas 负责低对比度液态背景，不引入 Three.js 或 GSAP。
- IntersectionObserver 负责一次性滚动显现。
- IntersectionObserver 或滚动位置计算负责文章目录激活状态。
- requestAnimationFrame 仅用于液态背景、阅读进度和必要的连续视觉更新。

## 4. 动效语言

统一使用以下视觉规则：

- 页面位移以 8–18px 为主，避免大幅飞入。
- 页面缩放最低不小于 0.985。
- 普通反馈持续 120–240ms。
- 面板和卡片持续 220–360ms。
- 页面切换持续 350–500ms。
- 优先使用 opacity、transform 和 CSS 变量，避免高频布局重排。
- 模糊只用于短暂过渡和低面积图层，不长时间覆盖正文。
- 强调色来自现有 `data-accent` 配置并同步到液态背景。

## 5. 页面切换

内部导航采用克制的液态遮罩切换：

1. 用户点击内部链接，链接产生按压反馈。
2. 当前页面缩放至约 0.985，并轻微降低透明度和清晰度。
3. 半透明液态遮罩从点击位置或导航方向扩散。
4. 新页面完成载入后，先显示页面标题，再显示正文或卡片。
5. 遮罩消散，页面恢复正常比例。

约束：

- 外部链接、下载、RSS、带修饰键点击和新标签页行为不得被拦截。
- 浏览器前进、后退必须保持可用。
- 页面切换期间不得造成重复点击、焦点丢失或滚动位置错误。
- 页面切换后必须重新初始化代码复制、设置面板、目录和滚动显现。

## 6. 液态背景

在现有摄影背景上增加独立 WebGL Canvas：

- 使用简单片元 Shader 生成缓慢流动的低饱和色域。
- 颜色由当前强调色、主题模式和页面类型共同决定。
- 鼠标或触摸只产生轻微、缓慢衰减的扰动。
- Canvas 使用 `pointer-events: none`，不阻挡页面交互。
- 页面不可见时停止 requestAnimationFrame。
- WebGL 初始化失败时保留现有静态背景。

页面强度：

| 页面 | 相对强度 |
|---|---:|
| 首页 | 100% |
| 文章列表 | 70% |
| 标签与归档 | 60% |
| 关于页面 | 55% |
| 文章正文 | 30% |
| 设置面板打开 | 暂时降低至 20% |

## 7. 顶部导航

- 当前页面指示线在导航项之间平滑移动。
- 鼠标经过导航链接时出现低对比液态底色扩散。
- 点击时提供短促压下反馈。
- 向下滚动时导航容器轻微收紧，向上滚动时恢复。
- Logo 圆点仅做低频呼吸，不持续闪烁。
- 移动菜单展开时容器柔和展开，导航项按短间隔依次出现。

## 8. 首页与列表

### 首页首屏

- Eyebrow、主标题、强调词和说明依次进入。
- 标题分行错开约 80ms。
- 强调词只执行一次柔和扫光，不循环播放。

### 文章卡片

- 首次进入视口时从下方约 16px 淡入。
- 多卡片按短间隔依次显示。
- 悬停时上浮、边框转为强调色、低对比光斑靠近指针。
- 按下时轻微收缩，然后进入页面切换。
- 不做大角度倾斜和持续跟随旋转。

## 9. 文章阅读

- 页面顶部增加约 2px 的阅读进度线。
- 文章标题、摘要、元信息和正文按层次一次性进入。
- 正文段落不逐段反复动画。
- 目录根据当前章节平滑移动高亮背景。
- 点击目录平滑滚动；目标标题获得一次低强度强调。
- 代码块悬停时边框轻微增强。
- 复制成功时按钮平滑切换为勾选状态，约 1.4 秒后恢复。
- 复制失败时提供明确失败反馈。

## 10. 标签、归档和通用控件

- 标签悬停时背景从中心柔和扩散，按下时轻微缩放。
- 归档时间轴随首次滚动逐步点亮，文章条目依次进入。
- 普通正文链接采用颜色过渡和下划线滑入，不使用液态遮罩。
- 所有按钮具有 hover、active、focus-visible 和 disabled 状态。
- 404 页面只使用背景环境动效，不增加干扰性互动。

## 11. 外观设置

- 设置面板从触发按钮附近缩放和淡入。
- 面板打开时液态背景降低强度。
- 深浅主题使用约 300ms 的颜色融合，避免白屏闪烁。
- 强调色变化通过 CSS 变量和 Shader uniform 同步过渡。
- 当前色点显示一次扩散环反馈。
- 点击面板外、Escape 和页面切换都能正确关闭面板。

## 12. 移动端与性能降级

移动端自动降级：

- WebGL 目标帧率最高 30 FPS。
- 设备像素比限制约 1.25。
- 降低 Shader 分辨率、扰动强度和更新频率。
- 缩短进入位移和动画持续时间。
- 文章正文页接近静态。
- 页面不可见后立即停止渲染。
- WebGL 不可用、低性能或初始化失败时显示现有静态背景。

当 `prefers-reduced-motion: reduce` 生效时：

- 停止 WebGL 连续动画。
- 关闭滚动视差和分层错位。
- 页面切换退化为快速淡入淡出。
- 平滑滚动改为直接定位或最短过渡。
- 所有功能和焦点反馈继续可用。

## 13. 性能预算

| 指标 | 目标 |
|---|---:|
| 新增压缩脚本 | 不超过 150KB |
| 首页首次额外传输 | 不超过 300KB |
| 页面切换 | 350–500ms |
| 桌面目标帧率 | 接近 60 FPS |
| 移动端帧率上限 | 30 FPS |
| 新增服务器常驻内存 | 0MB |
| 新增后台进程 | 0 |
| 大型动画依赖 | 不引入 |

## 14. 组件边界

预计新增或调整：

- 新增全局液态背景组件，负责 Canvas 生命周期、主题和强调色同步。
- 新增全局动效控制器，负责滚动显现、阅读进度和页面类型状态。
- 新增页面过渡遮罩组件。
- 调整 `BaseLayout.astro`，挂载全局组件并暴露页面类型。
- 调整导航、设置面板、代码复制和目录组件，使其支持页面切换后的幂等初始化。
- 扩充 `global.css` 的动效变量、状态类和 reduced-motion 规则。
- 必要时为首页、列表和文章布局增加语义化 data 属性，不改变内容结构。

## 15. 测试策略

自动测试覆盖：

- 生产页面包含全局动效和液态背景挂载点。
- reduced-motion 降级规则存在。
- WebGL 不支持时不会影响正文。
- 页面切换后代码复制不会重复绑定。
- 页面切换后设置面板仍可开关和保存设置。
- 阅读进度和目录仅在文章页启用。
- 外部链接和 RSS 不被内部页面切换逻辑错误拦截。
- 构建、现有 29 项测试和部署测试继续通过。

手工测试覆盖：

- 桌面深浅主题和全部强调色。
- Chrome/Edge 常规桌面尺寸。
- 窄屏移动布局和触摸交互。
- 浏览器前进、后退、刷新和直接访问文章地址。
- 快速连续点击导航。
- 页面隐藏后动画暂停。
- reduced-motion 和 WebGL 禁用场景。

## 16. 发布策略

1. 先完成测试和静态构建验证。
2. 本地预览桌面与移动端交互。
3. 检查构建体积是否满足预算。
4. 执行部署演练。
5. 正式部署并通过服务器源站检查。
6. 若发现页面切换影响基本导航，立即关闭增强层并保留静态回退。
