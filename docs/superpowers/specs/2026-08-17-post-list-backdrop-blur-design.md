# 文章列表磨砂背景设计

## 背景

首页“最近更新”和 `/posts/` 文章页都使用 `.post-list` 展示文章。当前列表直接叠在站点背景图上，仅在行悬停时显示轻微的强调色渐变。背景图细节较丰富时，列表文字和背景之间的分离度不足。

## 目标

- 为首页“最近更新”和文章页列表增加统一的背景模糊效果。
- 提升文字可读性，同时保留背景图片和现有杂志式排版的通透感。
- 保留现有列表分隔线、左侧悬停强调线和标题位移动效。
- 同时适配浅色主题、深色主题、移动端和不支持 `backdrop-filter` 的浏览器。

## 非目标

- 不把每一篇文章改造成独立卡片。
- 不改变文章列表的数据结构、排序、文案或链接行为。
- 不修改首页“精选文章”的现有卡片样式。
- 不把玻璃背景扩展到栏目标题或整个页面区域。

## 视觉方案

文章列表作为一块连续的磨砂玻璃面板：

- 模糊背景约 `16px`，并使用轻微饱和度增强，使背景色彩透出但不干扰阅读。
- 使用与主题匹配的低透明度表面色；深色主题保持偏深玻璃，浅色主题保持偏暖白玻璃。
- 使用约 `20px` 圆角和克制的边框、阴影，让面板与背景分离但不呈现厚重卡片感。
- 保留每行之间的分隔线。
- 列表内容增加适当的水平内边距，避免文字贴近圆角边缘。
- 第一行和最后一行的交互背景遵循外层圆角，防止 hover 渐变越出面板。

## 交互行为

- 行悬停和键盘聚焦继续显示现有强调色渐变。
- 左侧强调线和标题轻微横移保持不变。
- 磨砂面板本身不增加额外位移或缩放动画，避免与列表行动效竞争。
- `prefers-reduced-motion` 行为维持现有规则。

## 响应式与兼容性

- 桌面端使用完整玻璃模糊和约 `20px` 圆角。
- 移动端适当减小圆角、模糊强度及水平留白，控制渲染成本并保留内容宽度。
- 同时声明 `-webkit-backdrop-filter` 与标准 `backdrop-filter`。
- 在不支持背景模糊时，回退为较不透明的主题表面色，确保文字对比度。
- 纯色背景偏好仍使用同一表面样式，不依赖背景图片存在。

## 实现范围

主要修改 `src/styles/global.css` 中 `.post-list`、`.post-list-item__link`、响应式规则和现有 `@supports not (...)` 降级规则。由于首页与文章页共享 `.post-list`，原则上无需修改 Astro 模板。

## 验证

- 运行 `npm run check`。
- 运行 `npm test -- --run`。
- 运行 `npm run build`。
- 在首页和 `/posts/` 分别检查浅色、深色和窄屏布局。
- 检查键盘焦点、首尾行圆角、hover 渐变及不支持模糊时的降级背景。
