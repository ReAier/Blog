# 图片上传弹窗设计

## 目标

图片库顶部“上传图片”按钮始终可点击。点击后打开与后台统一风格的模态窗口，在窗口内填写所属文章 slug、选择一张或多张图片并确认上传。

## 交互

- 图片库工具栏中的文章 slug 只用于筛选。
- 打开弹窗时，如果筛选 slug 非空，将其作为上传 slug 的初始值；否则上传 slug 为空。
- 弹窗展示 slug 输入框、图片选择区、已选文件数量和文件名、取消按钮、确认上传按钮。
- slug 或文件未填写时不允许提交，并在弹窗内显示明确提示。
- 支持关闭按钮、遮罩点击和 Escape；上传过程中禁止关闭。
- 上传成功后关闭弹窗、刷新图片列表，并在页面显示成功消息。
- 上传失败时保留弹窗、slug 和文件选择，并在弹窗内显示错误。

## 范围

只修改图片库上传交互与对应样式/测试，不修改服务端上传 API、图片处理规则或文章编辑器内的图片素材上传。
