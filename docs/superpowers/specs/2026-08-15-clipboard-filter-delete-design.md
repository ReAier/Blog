# 剪切板筛选与删除设计

日期：2026-08-15

## 目标

修复后台剪切板按语言筛选后语言下拉选项缩减的问题，并在剪切内容列表中提供安全删除入口。

## 语言筛选

语言下拉框的候选项必须来自完整剪切内容集合，而不是当前语言筛选后的列表。列表请求仍按搜索词和所选语言返回匹配项，但响应同时提供不受当前筛选影响、去重并排序后的全部语言。客户端使用该字段渲染选项，因此选中 `cpp` 后仍可看到 `typescript` 等其他语言并直接切换。

## 删除交互

每张剪切内容卡片提供独立的“删除”按钮。按钮不能触发卡片的编辑导航。点击后显示包含剪切内容标题的浏览器确认框；确认后调用现有删除 API。删除成功时刷新列表并显示成功提示；失败时保留卡片并显示后端错误信息。删除期间禁用对应按钮，避免重复请求。

后端沿用现有安全规则：被文章引用的剪切内容不可删除，客户端只展示冲突错误，不自动移除文章引用。

## 测试与验收

- API 列表响应在应用语言筛选时仍返回完整语言集合。
- 列表页使用完整语言集合渲染下拉选项。
- 删除按钮阻止卡片导航，要求确认，并调用删除 API。
- 成功删除后刷新数据并显示提示；失败时显示错误。
- 运行 Vitest、Astro/TypeScript 检查及生产构建。
