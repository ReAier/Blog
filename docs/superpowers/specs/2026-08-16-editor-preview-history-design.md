# 编辑器图片预览与手动历史设计

日期：2026-08-16

## 目标

修复公网图片 Markdown 在后台即时预览中破图的问题；将文章历史限定为手动保存产生的版本；改善历史弹窗滚动、正文显示和按钮文案；删除编辑器空闲态“尚未修改”。

## 设计

- 图片正文继续允许使用 `https://blog.reaier.top/media/...` 公网地址。即时预览只将与 `BLOG_SITE_ORIGIN` 同源且位于 `/media/` 下的 URL 重写为后台 `/media/` 地址，以便未发布图片也能预览；其他外部图片保持不变。
- 文章编辑 API 使用显式 `X-History-Mode: manual` 标记手动保存。自动保存正常写文件但不记录历史；手动创建或更新记录历史。导入、删除、恢复、slug 迁移等生命周期动作维持现有历史。
- 历史详情接口增加正文结果，UI 不再展示 frontmatter。历史列表和右侧详情各自滚动，外层弹窗不承担内容滚动。
- “恢复此版本”改为“恢复”。文章和 Clip 编辑器在 idle 状态不渲染保存状态文字。

## 约束

- 不引入新依赖。
- 保留 800ms 自动保存和现有冲突处理。
- 保留公网图片 Markdown 复制能力。
