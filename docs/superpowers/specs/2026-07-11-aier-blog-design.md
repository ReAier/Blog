# Aier's blogs 设计规格

**日期：** 2026-07-11  
**站点：** `blog.reaier.top`  
**部署目标：** 阿里云 ECS `116.62.42.204`  
**设计方向：** 极简科技 × 克制毛玻璃  
**内容语言：** 中文为主

## 1. 目标

从零创建一个中文为主的个人静态博客，用于发布技术、AI、工程实践和个人随笔。站点应具有鲜明但克制的视觉风格、优秀的中文长文阅读体验、极低的服务器资源消耗和简单可靠的一键部署流程。

## 2. 技术方案

- 使用 Astro 构建纯静态站点。
- 使用 Astro Content Collections 管理 Markdown/MDX 文章。
- 使用 TypeScript 编写配置和必要的客户端交互。
- 不使用数据库、服务端渲染或常驻 Node.js 进程。
- 本机完成依赖安装、检查和生产构建。
- Nginx 只负责提供静态文件。
- Git 管理源码与文章历史。

## 3. 品牌与文案

- 完整站名：`Aier's blogs`
- 导航 Logo：`AIER.`
- 默认副标题：`关于技术、AI 与持续构建`
- 默认站点描述：`Aier 的技术笔记、工程实践与独立思考。`
- 主语言：简体中文 `zh-CN`
- 代码、命令和必要的技术术语保留英文。

所有品牌文案集中放在一个站点配置文件中，不分散硬编码到页面组件。

## 4. 信息架构

首版导航包含：

```text
首页 / 文章 / 标签 / 归档 / 关于 / RSS
```

页面范围：

- 首页：个人简介、最新文章、精选文章、标签入口。
- 文章列表：摘要、标签、发布日期、预计阅读时间、分页。
- 文章详情：正文、目录、代码高亮、上一篇/下一篇、返回顶部。
- 标签：标签索引与单标签文章列表。
- 归档：按年份与月份组织文章。
- 关于：个人介绍和站点说明模板。
- RSS：完整文章索引。
- 404：与站点视觉一致的错误页。

## 5. 内容模型

文章位于：

```text
src/content/blog/
```

Frontmatter 字段：

```yaml
title: string
description: string
publishedAt: date
updatedAt: date（可选）
tags: string[]
draft: boolean
featured: boolean
cover: string（可选）
```

构建规则：

- 生产构建排除 `draft: true` 的文章。
- 标签自动去重并生成对应路由。
- 文章按 `publishedAt` 降序排列。
- 阅读时间根据正文内容自动计算。
- 标题、描述、发布日期和标签必须通过内容 Schema 校验。

## 6. 视觉系统

### 6.1 基础风格

- 暖白浅色背景和深灰黑暗色背景，避免纯白与纯黑造成视觉疲劳。
- 使用极淡网格、柔和环境光和少量纹理形成空间层次。
- 页面布局保持大量留白、明确层级和不对称但稳定的节奏。
- 中文标题使用具有书面感的衬线字体；正文使用清晰的中文无衬线字体；代码使用等宽字体。
- 正文阅读宽度约 720px，并针对中文设置合适的字号、行高和段间距。

### 6.2 毛玻璃效果

毛玻璃只用于：

- 固定导航栏。
- 主题与强调色设置面板。
- 首页少量浮层或精选文章卡片。
- 移动端菜单。

正文容器保持高对比度实色背景。毛玻璃必须提供不支持 `backdrop-filter` 时的实色回退，不得影响文字可读性。

### 6.3 可选强调色

访客可在设置面板选择强调色。首版提供：

| 名称 | 色值 | 用途 |
|---|---|---|
| 橙红 | `#F05A3C` | 温暖、醒目，适合浅色模式 |
| 青绿 | `#16A085` | 冷静、技术感 |
| 靛蓝 | `#4F6BED` | 清晰、理性 |
| 琥珀 | `#D89016` | 温和、纸张感 |
| 玫红（默认） | `#C74776` | 默认强调色 |

实现要求：

- 所有强调色通过 CSS 自定义属性驱动。
- 选择结果写入 `localStorage`。
- 首次访问默认使用橙红色。
- 切换颜色不刷新页面。
- 控件具有文字标签或可访问名称，不能只通过颜色表达选择状态。
- 深浅模式下分别校验文本和交互元素对比度。

### 6.4 深浅模式

- 支持浅色、深色、跟随系统三种模式。
- 设置写入 `localStorage`。
- 页面加载前应用保存的主题，避免闪烁。
- 遵守 `prefers-reduced-motion`。

## 7. 功能范围

首版包括：

- Markdown/MDX。
- 代码语法高亮与复制按钮。
- 自动文章目录。
- 预计阅读时间。
- 标签、归档和分页。
- RSS、站点地图、canonical URL、Open Graph 元数据。
- 响应式布局。
- 深浅模式与可选强调色。
- 键盘导航、可见焦点、语义化结构和跳至正文链接。
- 一篇欢迎文章、一篇 Markdown 功能演示文章和关于页面模板。

首版不包括：

- 评论系统。
- 网页管理后台。
- 数据库。
- 用户注册或登录。
- 访问统计脚本。
- 全文搜索。
- 多语言路由。

这些功能可在后续版本独立增加。

## 9. 部署架构

采用本机构建、原子上传方案：

```text
本机 Markdown/Git
  -> Astro production build
  -> 压缩 dist
  -> SCP 上传
  -> 解压到新的 release 目录
  -> 切换 current 软链接
  -> nginx -t
  -> reload nginx
  -> HTTP 健康检查
```

服务器目录：

```text
/var/www/aier-blog/
├── releases/
│   └── <UTC timestamp>/
└── current -> releases/<current release>
```

Nginx 虚拟主机：

```text
server_name blog.reaier.top;
root /var/www/aier-blog/current;
```

部署脚本必须：

- 在上传前执行 Astro 检查和生产构建。
- 使用 UTC 时间戳创建独立版本目录。
- 在切换前确认 `index.html` 存在。
- 原子更新 `current` 软链接。
- 通过 `nginx -t` 后才重载 Nginx。
- 请求服务器本机并携带 `Host: blog.reaier.top` 完成健康检查。
- 失败时恢复到前一个软链接目标。
- 默认保留最近 5 个版本，不删除当前版本。

## 10. Nginx 与现有服务隔离

- 新建独立的 `/etc/nginx/conf.d/blog.conf`。
- 不修改 `/etc/nginx/conf.d/astrbot.conf` 的业务代理逻辑。
- 博客只使用静态文件，不新增容器和监听端口。
- UFW 保持仅允许 SSH、HTTP 和 HTTPS。
- 部署前备份 Nginx 配置与当前站点目录状态。

## 11. DNS、备案与 HTTPS

- `blog.reaier.top` 的 A 记录已解析到 `116.62.42.204`，TTL 为 600 秒。
- 当前域名正在进行 ICP 备案。
- 首次部署先配置 HTTP；公网可能继续显示阿里云未备案拦截页。
- 服务器本机通过 Host 请求验证博客实际内容。
- 备案通过后，使用已安装的 Certbot 为 `blog.reaier.top` 申请证书，启用 HTTPS 和 HTTP 到 HTTPS 跳转。

## 12. 验收标准

- `npm run check` 和 `npm run build` 成功。
- 首页、文章、标签、归档、关于、RSS、404 均生成。
- 深浅模式和五种强调色可切换并持久化。
- 手机、平板和桌面布局无横向溢出。
- 关闭 JavaScript 后文章正文与导航核心链接仍可访问。
- Nginx 配置检查成功。
- 服务器本机携带博客 Host 请求返回博客首页。
- `astrbot.reaier.top` 仍正常指向 AstrBot。
- 博客不新增常驻进程，部署后服务器内存占用没有显著增加。
- 发布脚本可从一个版本回滚到上一个版本。

## 13. 回滚

- 代码：通过 Git 提交回滚。
- 站点文件：将 `/var/www/aier-blog/current` 原子切回上一个 release。
- Nginx：恢复部署前备份并执行 `nginx -t && systemctl reload nginx`。
- 部署失败不得删除上一版本或影响 AstrBot 配置。
